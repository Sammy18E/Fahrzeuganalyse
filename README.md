# Datengetriebene Automobilforschung
Praxisprojekt Datenvisualisierung Python



**Beschreibung:**
Analysiere und visualisiere die Fahrzeugeigenschaften im Automobilforschungsdatensatz




**Aufgabenstellung:**

Deine Aufgabe ist es, geeignete Daten für das Projekt zu explorieren und zu analysieren.
Visualisiere die wichtigsten Erkenntnisse in informativen Grafiken.

  ● Datensuche: Nutze die bereitgestellten Daten und ergänze sie ggf. mit Statistiken aus dem Internet.
  
  ● Analyse & Visualisierung: Führe die Analyse und Visualisierung in Python durch.
  
  ● Abschlussbericht: Erstelle einen Bericht mit 10 unterschiedlichen Grafiken. Dieser kann als Dashboard, Jupyter Notebook oder PowerPoint-Datei präsentiert und eingereicht werden. Füge bei der Abgabe auch den Code und ggf. Screenshots bei.
  
  ● Präsentation: Bereitet eine ca. 20-minütige Präsentation vor, in der jedes Gruppenmitglied einen Redeanteil hat (ca. 5 Minuten Redezeit pro Person).
  
  ● Bewertungskriterien: Die Bewertung erfolgt in den Kategorien Datenanalyse, Projektarchitektur, Visualisierung und Präsentation.
